# 🧠 AI-Powered Personalized Learning Assistant

> An open-source **EdTech AI platform** that combines the power of **Large Language Models (LLMs)** and **Retrieval-Augmented Generation (RAG)** to deliver personalized, adaptive learning experiences.  
>  
> Built with **FastAPI**, **LangChain**, and **React** *(frontend currently in development)*.

---

## 📢 Project Status

🚧 **Currently under active development**
- ✅ Backend (FastAPI + LangChain + RAG pipeline) — functional and ready for API testing.
- ⚙️ Frontend (React + Tailwind CSS) — in progress; UI components and integration under development.
- 🧪 Next Steps — connect frontend with API endpoints and deploy the MVP version.

Follow this repository for updates as new features roll out!

---

## 💡 Tech Stack
**Backend:** FastAPI, LangChain, OpenAI API / Hugging Face, FAISS / Pinecone, PostgreSQL  
**Frontend:** React, TypeScript, Tailwind CSS *(in progress)*  
**Auth:** JWT-based secure authentication
